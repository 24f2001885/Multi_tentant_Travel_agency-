1. Executive Summary & Full Milestone Scope (P7 – P14)

The Trek Management Application (TMA) has been transformed into a complete multi-tenant, enterprise-grade SaaS platform capable of serving hundreds of independent trekking agencies on a shared PostgreSQL engine with custom domains, isolated sessions, automated money distribution, and rigorous security boundaries.

2. Detailed Breakdown of Built Milestones

Milestone P7: Tenancy Core & Security Hardening

  • Subdomain and custom domain host resolver (platform.localhost:5000 vs <subdomain>.localhost:5000).
  • Universal TenantScopedMixin with automatic tenant filtering.
  • Platform Superadmin control plane for onboarding and suspending tenants.
  • E.164 phone normalization, mandatory Terms of Service acceptance gate, and host-only session cookies.

Milestone P8: Identity, RBAC & Access Governance

  • Centralized granular capability catalog.
  • Custom Role Builder allowing tenant admins to define custom staff roles with selective permissions.
  • Protected capabilities guard (roles.manage, staff.manage, org settings) reserved exclusively for Tenant Owners.
  • Fast session snapshot capability caching.

Milestone P9: Booking Engine v2 & Money Platform

  • Multi-participant bookings capturing participant details, dietary restrictions, and emergency contacts.
  • Promotional coupon engine with usage limits, minimum thresholds, and tenant isolation.
  • Tiered refund policy engine calculating automated refunds based on departure time windows.
  • Automated tax invoicing with sequential numbers, GST breakdown, and WeasyPrint vector PDF generation.
  • FIFO waitlist queue with automated sweeps on cancellations and timed offer windows.
  • Razorpay Route marketplace split-payment transfers and webhook processing.

Milestone P10: Trek Content, Discovery & Itineraries

  • Structured multi-day itineraries with categorized daily elements (activity, meal, transport, accommodation, note).
  • Vector PDF branded trek brochure exports.
  • Media gallery with automatic EXIF/GPS coordinate stripping via Pillow and UUID storage.
  • Staff trek creation workflow landing in pending status awaiting admin approval.
  • Verified trekker reviews restricted to completed bookings with reviewer privacy masking.

Milestone P11: Communication Platform & Messaging Compliance

  • Omnichannel notification dispatcher handling Email, SMS, and WhatsApp Cloud API.
  • Critical notification carve-out: operational alerts bypass marketing opt-outs while respecting legal unsubscribes.
  • Consent and preference ledger (NotificationConsent) and RFC 8058 one-click unsubscribe headers.
  • Marketing message campaigns with audience segmentation and mandatory test-send gates.
  • Meta WhatsApp Cloud API webhook with HMAC-SHA256 signature verification and monotonic receipt updates.

Milestone P12: Support v2 (Multi-turn Ticketing)

  • Multi-turn messaging thread model via ticket_messages table.
  • A ticket stays open as a running conversation until the raising Trekker, and only the raising Trekker, marks it resolved.
  • Staff and Admin can reply back and forth without prematurely closing the inquiry.
  • Staff scoping preserved: Staff sees only problem tickets on treks assigned to them; query tickets remain Admin-only.

Milestone P13: Backup, Monitoring & Hardening

  • Self-serve tenant data export: Tenant Admin can generate and download a compressed .json.gz backup of their entire data footprint.
  • Cross-tenant backup isolation: Tenant A cannot download Tenant B's backup archives (HTTP 404).
  • Platform Admin full disaster recovery snapshots and targeted tenant exports.
  • Business and infrastructure monitoring: GMV volume, platform take-rates, disk utilization, scheduler jobs, and table row counts.
  • Immutable meta-audit log (PlatformAccessLog) tracking all cross-tenant superadmin actions.

Milestone P14: Paused P6 Enhancements, Validation & CI

  • Client-side form validation layer (form_validation.js) enforcing date sanity, E.164 phone formats, and instant feedback.
  • Dynamic Chart.js rendering (charts.js) across Admin Dashboard, Staff Dashboard, and Reports.
  • Bootstrap responsive styling pass (custom.css) for mobile layouts and tables.
  • GitHub Actions CI workflow (.github/workflows/test.yml) with the cross-tenant isolation suite as a mandatory blocking gate.
  • End-to-End user journeys (tests/e2e/test_journeys.py) covering public browsing, registration, and tenant onboarding.

3. Local Machine Runbook (Step-by-Step)

Step 1: Configure Windows Hosts File

127.0.0.1 platform.localhost
127.0.0.1 tenantzero.localhost
127.0.0.1 a.localhost
127.0.0.1 b.localhost

Step 2: Start Docker Containers

docker compose build
docker compose up -d

Step 3: Run Migrations & Seeds

# Apply all database migrations (Baseline through P13)
docker compose exec web flask db upgrade

# Seed Platform Superadmin, Tenant Zero, Admin, and RBAC
docker compose exec web flask seed-platform-admin
docker compose exec web flask seed-tenant-zero
docker compose exec web flask seed-admin
docker compose exec web flask seed-rbac
docker compose exec web flask backfill-consents

Step 4: Execute Test Suite

# Run complete test suite (Unit, Integration, Isolation, E2E)
docker compose run --rm test
